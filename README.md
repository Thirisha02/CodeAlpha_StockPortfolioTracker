# CodeAlpha_StockPortfolioTracker
## Description
A Python-based Stock Portfolio Tracker developed for the CodeAlpha Python Programming Internship. It allows users to manage stock investments, calculate total portfolio value, and save the portfolio summary to a text file.
## Features
- Add stocks and quantity
- Calculate total investment
- Display portfolio summary
- Save portfolio to a text file
- User-friendly interface

## Technologies Used
- Python 3
